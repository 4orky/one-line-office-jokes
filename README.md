One single line that makes office life funny. The program writes one line to `/output/entry.txt`:

> We switched to hot-desking so nobody owns a desk, but Karen's mug has squatter's rights.

## Method

Fourteen original candidates were drafted by hand against the brief — a real detail of office life, with the laugh landing in the last few words — and scored 0–10 on five criteria (real detail, punch in the last words, joke not complaint, freshness, tightness). The winner scored 48/50; two runners-up tied at 47 ("per my last email" and the Wi-Fi password intern). A revision pass then cut two words from the winner ("moved to" → "switched to", "yet somehow" → "but") so the punch lands sooner, re-scored tightness 9 → 10. Selection is deterministic: highest score wins, ties go to the shorter text.

## Run it

```sh
python3 main.py
```
